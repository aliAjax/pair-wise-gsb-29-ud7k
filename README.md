# 交班核对台（夜间骑手换班）

- 行业：物流（城市末端配送）
- 技术栈：Vue3、Vite、TypeScript、Element Plus、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 数据保存在浏览器 localStorage（未完成草稿 + 已封存交班记录），方便后续接后端接口。

## 业务流程

1. **现金核平（闸门一）**：登记交班骑手手里未送完的订单，每单记录接班骑手（交接人）、是否冷链/占冷冻格数、已收现金。
   系统汇总各单已收现金，与交班骑手实际上交现金核对；差额为 0 才放行到下一步。
2. **班长复核**：现金有差额（长款/短款）时流程暂停，必须由班长登记复核意见后放行；改动上交金额会使放行失效。
3. **路线与冷冻格确认（闸门二）**：按剩余路线站点顺序（stopIndex 升序）逐单判断——
   常温单不占冷冻格直接承接；冷链单顺序占用接班车冷冻格，某单装不下时**留在原骑手**并写明原因（需要格数 / 剩余格数 / 站点），后续单继续判断。
4. **完成换班**：封存交班记录（单号、双方骑手、现金核对、班长复核、每单归属与留单原因），可在「交班记录」页查询明细。

## 分层

- `src/lib/route.ts`：路线判断与现金核平（纯函数，可独立测试）
- `src/lib/money.ts`：金额（分/元）换算与格式化
- `src/stores/handover.ts`：交班记录与草稿的持久化、工作流闸门（记录层）
- `src/pages/*`、`src/components/*`：页面与弹窗（视图层，与判断逻辑分开）
